SHREE SHYAM CHANACHUR WEBSITE
================================

Files:
- index.html  : complete website
- style.css   : responsive premium cream/maroon/gold design
- script.js   : product cards, mobile menu and WhatsApp ordering
- assets/shree-shyam-chanachur.jpg : uploaded product/branding image

HOW TO RUN:
1. Keep the folder structure unchanged.
2. Open index.html in Chrome/Edge.
3. For development, use VS Code + Live Server.

CUSTOMIZE:
- Edit products in script.js.
- Edit phone number in index.html and script.js.
- Replace the uploaded product image with approved product photos.
- Confirm all prices, ingredients, certifications and packaging claims before publishing.
